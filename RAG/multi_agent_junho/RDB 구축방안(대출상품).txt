<RDB 구축방안>

주어진 csv파일과 yml파일 바탕으로 SQL_agent 구축하려고 하는데, 사용자가 대출 및 대출상품에 대한 질의에서 특정 키워드를 추출하여 DB에서 조회하는 agent 구성하고자함

- 구축 DB => csv파일 기준
- 컬럼 => 은행명, 상품명, 종류, 상세종류, 대출대상, 대출조건, 대출기간, 대출한도
- 사용자가 '대출'관련해서 요청이 들어오면 대출상품을 DB에서 조회함
- 중요 추출 키워드 => 1. 대출대상, 2. 대출조건
- 키워드 추출(대출대상) => 공백(띄어쓰기, 들여쓰기)에 영향을 받지 않도록 조정 필요 (예: 개인 사업자=> 개인사업자, 주택 건설 등록 업자=> 주택건설등록업자 )
- 위의 조건에 맞게 은행명, 상품명, 종류, 상세종류, 대출대상, 대출조건, 대출기간, 대출한도에 대한 테이블 조회

<키워드 탐지>
- DB에서 상세종류, 대출대상에서 unique한 키워드 추출 후 리스트에 저장
- 사용자 질의에서 공백을 고려하여 상세종류 및 대출대상이 추출되면 query문으로 조회 => 둘 중 하나만 조회되면 해당 컬럼을 기준으로 조회
- 상세종류, 대출대상 모두 탐지 되지 않는 경우, 대출조건에서 단어를 추출하고, 탐지빈도가 높은 순으로 테이블 정렬
